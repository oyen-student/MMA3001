# Dataset license and attribution

The DTMB 5415 dataset is a third-party work. It is not covered by this
repository's MIT license, and the dataset archive is intentionally not
committed here.

The [Zenodo record](https://zenodo.org/records/19222008) metadata identifies
the dataset license as **Creative Commons Attribution 4.0 International
(CC BY 4.0)** (`CC-BY-4.0`). The record is authored by Andrea Serani and Matteo
Diez and has DOI [10.5281/zenodo.19222008](https://doi.org/10.5281/zenodo.19222008).
The record's API metadata was checked on 2026-10-23. If Zenodo updates the
record, check its current license metadata before redistributing the data.

When reusing or redistributing the dataset, follow the [CC BY 4.0 legal
code](https://creativecommons.org/licenses/by/4.0/). In particular, provide
appropriate credit, link to the license, and indicate whether changes were
made. A suggested attribution is:

> Serani, Andrea, and Matteo Diez. *Design-Space Dimensionality Reduction
> Benchmark Dataset – DTMB 5415 Hull*. Zenodo, 2026.
> https://doi.org/10.5281/zenodo.19222008. Licensed under CC BY 4.0.

The repository README explains how to obtain the archive. Keep the dataset's
attribution and license information with any copy shared outside this
repository. This note summarizes the published terms; it does not replace the
license text or the source record.
